# AI & Innovation

Where I've moved from using AI tools to helping build the product infrastructure that makes AI features trustworthy.

## Hands-On Work

- **Multi-agent orchestration** — contributed to architecture spanning 4+ domain agents on Cisco's AI-Native program
- **Evaluation frameworks** — helped define accuracy thresholds (85%+) across 14 evaluation areas so AI features have a shared bar before release
- **Eval Studio** — delivered a demo of synthetic data generation and interface evaluation tooling to the MCP team
- **Daily tools** — GitHub Copilot, Atlassian Rovo, agentic AI workflows

## Credentials

## Why This Matters to Product Work

Most product owners are learning to use AI tools. Fewer have sat inside the process of deciding whether an AI feature is *good enough to ship* — the evaluation criteria, the accuracy thresholds, the integration testing across teams. That's the part I've been doing hands-on this past year, and it's the direction I want to keep building in.
